# NEXFOLIO — Hybrid Web App

Personal Portfolio untuk **Moh. Kurniawan Sobari, S.H.**

Arsitektur **Hybrid**:

- **Frontend** → di-*host* di **Vercel** (static site: HTML + CSS + JS)
- **Backend** → **Google Apps Script** (REST JSON API)
- **Database** → **Google Sheets**
- **Proxy** → Vercel Serverless Function (`/api/proxy`) untuk meneruskan request & menghindari CORS
